# 스터디 참가 신청

스터디 참가 신청, 대기, 취소, 정원 변경 기능을 구현한 실습 프로젝트입니다.

- 환경: Java 21, Spring Boot 4.1.2
- 실행: `greeting-api/`에서 `./gradlew bootRun` (Windows는 `.\gradlew.bat bootRun`)
- 화면: http://localhost:8080/study.html

## 역할과 규칙

- `StudyController`: 요청 값을 받아 Service를 호출하고 결과 문자열을 반환
- `StudyService`: 신청, 취소, 정원 규칙과 명단 관리
- 대기자 선택: 명단이 신청 순서를 유지하므로 앞에서부터 찾은 대기자를 먼저 확정으로 변경

## API와 출력 형식

| 요청 | 요청 값 | 응답 예시 |
| --- | --- | --- |
| `POST /study/participants` | `name` | `신청 성공: id=1, 이름=철수, 상태=확정` |
| `GET /study/participants` | | `id=1, 이름=철수, 상태=확정` (한 줄에 한 명) |
| `POST /study/cancel` | `memberId` | `취소 성공: id=1, 이름=철수, 상태=확정` |
| `POST /study/capacity` | `capacity` | `정원 변경 성공: 현재 정원=4` |

승격이 있으면 다음 줄에 `승격: id=4, 이름=대기1, 상태=확정`을 함께 표시합니다.
실패는 `신청 실패 (이유)`, `취소 실패 (이유)`, `정원 변경 실패 (이유), 현재 정원=3` 형식입니다.

## 발견한 문제와 수정

| 문제 | 수정                                        |
| --- |-------------------------------------------|
| 이름 없이 신청하면 방문자로 등록됨 | `defaultValue`를 빼고 `required = false`로 변경 |
| 정원 변경 성공 후에도 실제 정원이 3으로 고정됨 | `capacity` 필드를 추가해 신청, 승격 조건에 사용          |
| 전각 공백이 붙은 이름이 중복 검사를 통과함 | `trim()`을 `strip()`으로 변경                  |
| 정원 변경 실패 시 현재 정원이 표시되지 않음 | 실패 문구에 현재 정원 추가                           |

수정 후 다시 실행해 위 결과를 확인했습니다.
