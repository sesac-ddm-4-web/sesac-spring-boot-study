Roulink 테스트 콘솔

1. 링크 생성 POST /shortenUrl

결과가 여기에 표시됩니다.

2. 접속(리다이렉트) GET /{key}

리다이렉트되면 "리다이렉트", 없으면 404, 만료면 410이 표시됩니다.

상태 확인은 캐시를 쓰지 않고 서버에 직접 요청합니다. 새 탭에서 열기는 브라우저가 301을 캐시할 수 있어 조회수가 안 오를 수 있습니다(302 권장).

3. 정보 조회 GET /shortenUrl/{key}

원본 URL, 키, 조회수가 표시됩니다.

4. 즉시 만료 DELETE /shortenUrl/{key}

성공하면 204, 토큰이 틀리면 403, 없는 키는 404입니다.

내가 만든 링크 브라우저에 저장된 목록 (서버 데이터와는 별개)

아직 만든 링크가 없습니다.

자동 시나리오 정상/오류 케이스를 한 번에 실행

기대 결과는 현재 구현 기준입니다(409 중복, 403 토큰 오류, 400 입력 오류, 410 만료). 미사용 자동 만료는 시간이 필요해 포함하지 않았습니다.
