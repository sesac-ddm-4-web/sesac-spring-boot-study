위시리스트와 장바구니

외부 상품을 찾아 위시리스트로 가져오고, 장바구니에 담아 쿠폰별 결제 금액을 미리 봅니다.

외부 상품 검색

DummyJSON 상품을 내 서버를 통해 조회합니다. 가져오면 가격이 원화(1단위 = 1,000원)로 환산되어 저장됩니다.

검색 결과가 없습니다.

직접 등록

이름은 1~100자, 가격은 0원~1억 원입니다.

예산 추천

가격이 예산 이하인 상품을 싼 순서로 최대 3개 보여 줍니다.

    위시리스트

    외부에서 가져온 상품은 이름·가격을 수정할 수 없습니다. 품절 상품은 저장만 되고 장바구니에는 담을 수 없습니다.

    id이름가격재고

    장바구니

    담을 때의 이름·가격·재고가 복사됩니다. 한 상품은 최대 5개, 최대 20종까지 담을 수 있습니다.
